# Sherlock Maps documentation

Sherlock Maps is a self-hosted Google Maps crawler and lead-generation suite. It
extracts business data, enriches companies with email addresses from their
websites, and exposes everything through a REST API and a Next.js dashboard.

- [Configuration](configuration.md) — ports, environment variables and crawler options.
- [REST API](api.md) — endpoints, request examples and responses.
- [Architecture](architecture.md) — how the crawler, API and UI fit together.
- [Browser profile](browser-profile.md) — use your own Chrome cookies, logins and extensions.
